# Contributing

Gatehouse is maintained as a personal portfolio project and is not currently accepting external contributions.

The repository still follows a disciplined contribution workflow internally:

1. create a focused branch;
2. add or update tests first;
3. preserve the security and concurrency invariants in `docs/IMPLEMENTATION_SPEC.md`;
4. update public documentation and test evidence;
5. run focused, regression, security, and repository-hygiene checks;
6. merge only after the release gate passes.

Public issue reports must not contain credentials, provider account details, request bodies, response bodies, or private documents.
